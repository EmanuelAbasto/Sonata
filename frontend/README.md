# Audio Uploader UI

Frontend web para el sistema de Audio Uploader. Permite subir archivos de audio, ver el estado de procesamiento y consultar resúmenes generados por IA.

## Tecnologías

- React 18 + TypeScript
- Vite
- Material-UI (MUI)
- Axios
- React Dropzone
- SCSS

## Requisitos previos

- Node.js 18+
- npm o yarn

## Instalación

```bash
git clone git@gitlab.com:jala-university1/cohort-2/ES.CSPR-471.GA.T2.26.M1/SB/emanuel.abasto/frontend.git
cd audio-uploader-ui
npm install
